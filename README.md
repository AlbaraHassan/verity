# Verity

Data analysis on your own computer: worksheets, statistics, control charts, dashboards and an AI analyst.
Includes a 14-day trial.

## Download

Website: https://albarahassan.github.io/verity/


- **Mac** (Apple silicon, M1 or newer): [Verity-macOS.dmg](https://github.com/AlbaraHassan/verity/releases/latest/download/Verity-macOS.dmg)
- **Windows** (64-bit): [Verity-Windows-Setup.exe](https://github.com/AlbaraHassan/verity/releases/latest/download/Verity-Windows-Setup.exe)

## First start

- **Mac:** open the DMG, drag Verity to Applications and open it. The app is signed and notarized by Apple.
- **Windows:** run the installer (no admin rights needed). If Windows shows "Windows protected your PC",
  click More info, then Run anyway.
